# Public hash center

`SOURCE-FILES.sha256` is the ordered SHA-256 manifest for the selected first-result
source, original result rows, independently reproduced Python output, and separate
81-kernel browser-witness bytes.

The repository keeps these identifiers distinct:

- `SH`: source Git commit/tree/blob identity.
- `SHA`: SHA-256 over one exact public byte string.
- `HASH`: the ordered manifest/root commitment connecting the selected evidence set.
- `HBP`: tuple-text measurement/provenance rows.
- `HBI`: the bounded pointer joining those surfaces.
